# Bayes’ Theorem (베이즈 정리)

“Bayes’ theorem, gives a mathematical rule for inverting conditional probabilities, allowing the probability of a cause to be found given its effect” - WIKIPEDIA

Bayes’ Rule은 과거 머신 러닝 / 현대 딥러닝 모델의 핵심 부품들 중 하나이며 데이터의 feature와 class 간 확률적 연결을 도모하는 수식이다. 특히 데이터의 모든 feature가 조건부 독립이라는 가정 하에 강력한 classification 확률 모델이 될 수 있으며, 이러한 classification task 외에도 generative model이 수식적으로 타당하게 만들어준다.

## 1. Definition

$$
P(A \mid B) = \frac{P(B \mid A) P(A) } {P(B)}, \ \ \ \ \mathrm{where} \ \ P(B) \neq 0
$$

### proof.

by definition of conditional probability…

$$
P(A \cap B) = P(A \mid B) P(B) , \ \ \ P(A \cap B) = P(B \mid A) P(A)
$$

Thus,

$$
P(A \mid B)P(B) = P(B \mid A) P(A)
$$

$$
P(A \mid B) = \frac{P(B \mid A) P(A)}{P(B)} , \ \ \mathrm{if} \ \ P(B) \neq 0
$$

where,

- $$P(A)$$: Prior (사전 확률)
- $$P(B \mid A)$$: Likelihood (가능도)
- $$P(B)$$: Evidence (marginal likelihood)
- $$P(A \mid B)$$: posterior (사후 확률)

In here $$P(B)$$ can be interpreted as a normalizer which make $$\underset{A}{\sum}P(A \mid B) = 1$$.

즉, 데이터들 중 일부 경우에는 $$P(A \mid B)$$와 $$P(B \mid A)$$ 중 한 가지만 구하기 쉬운 반면, 나머지 하나는 계산하기 어려운 경우가 있다. 이러한 경우에 Bayes rule은 구하기 어려운 확률을 계산해주는 정리이다. 이러한 경우는 주로 ‘관측된 데이터로부터 원인을 추론해야하는 문제’들이 대부분인데, 밑의 Usage에서 살펴보도록 하자. 

## 2. Understand

### Update prior with Bayes’ rule

Bayes’ rule allows us to “**update the probability”** of a cause after observing on outcome. Let the prior of event $$A$$ be $$P(A)$$. This is probability before knowing the new event (data) $$B$$. With given new $$B$$, ($$A$$ and $$B$$ are subset of sample space $$\Omega$$) we can add **correlation** between two different events. Then we can compute the probability of $$A$$ given $$B$$: $$P(B \mid A)$$ and $$B$$ given $$A$$: $$P(A \mid B)$$. But most in case, $$P(B \mid A)$$ is easier to compute rather than $$P(A \mid B)$$. 

Thus, we can get $$P(A \mid B)$$ By using Bayes’ rule given that we already measure $$P(B \mid A)$$ by modeling empirical estimation.

Now consider a new event (data) as $$C$$ ($$C \sub \Omega$$). Now, our old posterior become the new prior and we can compute the more-finegrained probability $$P(A \mid B, C)$$ with Bayes’ Rule again. By doing this sequence of Bayes’ rule, the prior probability $$P(A)$$ became more objective based on observed data.

Remind! The Bayes’ Rule deals with the **correlation** between $$A$$ and $$B$$, rather than its causality.

### Conditional independence $$B$$ and **$$C$$**

Most in case, Bayes’ rule operate based on the observed data $$B$$ and $$C$$ are conditionally independent $$P(B, C \mid A) = P(B \mid A) P(C \mid A)$$.

If it’s not…

$$
P(A \mid B, C) = \frac{P(B, C \mid A) P(A)}{P(B, C)}
$$

$$P(B, C \mid A)$$ become chaotic because $$B$$ and $$C$$ can be related.

So, How do we verify the whole features are conditional independent?

## 3. Usage

### Naive Bayes Classifier

기존의 discriminator가 단순히 $$P(C_k \mid \textbf x)$$를 학습했다면, Naive Bayes Classifier는 베이즈 룰을 이용해 반대로 $$P(\textbf x \mid C_k)$$와 $$P(C_k)$$를 학습하여 class가 주어졌을 때 $$\textbf x$$에 대한 우도를 학습한다. 그래서 generative classifier라고 불리기도 한다. 한편, 데이터가 적을 때 Naive bayes classifier가 단순 discriminator보다 유리하다고도 한다.

Naive Bayes is a conditional probability model: it assigns probabilities $$P(C_k \mid \textbf x)$$ for each of the $$K$$ possible outcome or classes $$C_k$$ given problem instance to be classified, where $$\textbf x = (x_1, \dots, x_n)$$

When number of features ($n$) got bigger, then basing such a model on probability table is infeasible because of the curse of dimension. Thus, the model is reformulated to make it more tractable with using Bayes’ theorem, the conditional probability can be decomposed as:

$$
P(C_k \mid \textbf x) = \frac{P(\textbf x \mid C_k)P(C_k)}{P(\textbf x)}
$$

Now our interest is getting numerator which is equivalent toe the joint probability $$P(C_k, x_1, \dots, x_n)$$  and ignore $$P(\textbf x)$$ because it is not important in discriminate task.

which can be rewritten as follow, using the **chain rule** of repeated applications of the definition of conditional probability like below.

$$
\begin{align*}
p(C_k, x_1, \ldots, x_n) 
&= p(x_1, \ldots, x_n, C_k) \\
&= p(x_1 \mid x_2, \ldots, x_n, C_k)\, p(x_2, \ldots, x_n, C_k) \\
&= p(x_1 \mid x_2, \ldots, x_n, C_k)\, p(x_2 \mid x_3, \ldots, x_n, C_k)\, p(x_3, \ldots, x_n, C_k) \\
&= \cdots \\
&= p(x_1 \mid x_2, \ldots, x_n, C_k)\,
   p(x_2 \mid x_3, \ldots, x_n, C_k)\,
   \cdots \\
&\quad p(x_{n-1} \mid x_n, C_k)\,
   p(x_n \mid C_k)\,
   p(C_k)
\end{align*}
$$

Thus, under the assumption which $$x_1, x_2., \dots, x_n$$ are **conditional independent** given $$y$$,

$$
P(C_k, \textbf x) = P(C_k)\prod^n_{i=1}P(x_i \mid C_k)
$$

For simply put, Naive Bayes modeling $$C_k$$ with decomposed feature unlike general discriminator directly modeling $$P(C_k \mid \textbf x)$$.

즉, 이미지와 같은 고차원 데이터에서는 classificaition 문제인 $$P(C_k \mid \textbf x)$$를 직접 계산하기 위해선 모든 feature의 조합 확률을 알아야하는 반면, Naive Bayes model과 같이 베이즈 룰을 이용하면 각 feature별 확률만 계산해도 되는 단순한 modeling 문제로 바뀌게 된다.

흥미롭게도, 실제로 이러한 조건부 가정이 거의 대부분 task의 데이터에서 거짓인 경우가 많은데, 그럼에도 결과적으로 분류가 잘 되는 경우가 많다. 중요한 것은 절대적인 확률의 정확도가 아니라 라벨 간 순위이기 때문이다.

또한 단순 판별 task에서는 $$P(\textbf x)$$를 상수 취급한다. 즉, 주어진 데이터에 대한 분포를 구하거나, $$\textbf x$$에 대한 판단은 고려하지 않는다. (이것을 고려하고 샘플링하는게 생성모델의 목적이다)

### Connection between Discriminative model and Generative model

Now let’s see how Bayes’ rule connects discriminative task and generative task. In general, the main goal of a generative models is modeling the complex distribution of class in order to sampling images.

A generative model is a statistical model of the joint probability distribution $$P( \textbf x \mid C_k)$$ on a given observable variable $$\textbf x$$ and target class $$C_k$$. On the other hand, a discriminative model us a model of the conditional probability $$P(C_k \mid \textbf x)$$ of the target class $$C_k$$, given an observation $$\textbf x$$.

### Classifier guidance

to generate $$\textbf x$$ under the class condition $$C_k$$, conditional generative model use **CIassifier  Guidance** which form of log-scored function with using bayes’ theorem.

$$
\log P(\textbf x \mid C_k) = \log P(C_k \mid \textbf x) +\log P(\textbf x) -\log P(C_k) 
$$

take a differential of the above..

$$
\nabla_x \log P(\textbf x \mid C_k) = \nabla_x \log P(C_k \mid \textbf x) + \nabla_x \log P(\textbf x)
$$

which semantically means score of condition of prompt ($$\nabla_x \log P(C_k \mid \textbf x)$$) plus score of image reality ($$\nabla_x \log P(\textbf x)$$).
